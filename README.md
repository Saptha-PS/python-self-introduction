# python-self-introduction
A beginner python program that creates a simple self-introduction using details entered by the user.
## About the project
This program asks the user to enter some personal details such as their name, age, year of birth, place ,skills, dream job and hobbies.
It then uses the entered information to display a simple self-introduction.
## Information used
-Name
-Age
-Year of birth
-Place
-Who they live with
-Skills
-Dream job
-Hobbies
## Concepts used
-'input()'
-'print()'
-Variables
Strings
## What I learned
This project helped me practice taking user input, storing information in variables, and displaying the information using python.
